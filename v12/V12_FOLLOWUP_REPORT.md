## 任务 1｜修好评估协议，并得到**第一个不受混淆的棋力读数**

### 1.1 我修掉了自己工具里的同一个缺陷

新协议 `v12/tools/eval_paired_seats.ts`：

| 旧协议的问题 | 新协议的处理 |
|---|---|
| 候选只坐 P0/P1 | **每个座位都跑**（`--seats 0,1,2,3`） |
| 种子 `20260924 + k*100003`，不在训练分布 | **归档种子**（`2026070501..`） |
| `new HeuristicAI()` 未播种 → 回退 `Math.random`（**正是 V11-D01**） | 每个座位一条**确定性派生流** `mulberry(hash(seed, seat))`，两臂完全相同 |
| 单一胜率，座位偏向无法分离 | **镜像配对**：每个 (seed, seat) 跑两局 —— CANDIDATE（候选坐该座位）+ MIRROR（四座位全启发式），**唯一差别是谁坐那个座位** |

**自检通过**：`--candidate heuristic` 时两臂逐位相同，`allDeltasZero = true`。

### 1.2 结果（`v12/out/protocol_v2/paired_budget_s42.json`）

```
每座位：  seat | candW/mirrorW | delta | 截断 | fallbacks | p50
          P0   | 0/0           | +0.00 | 0/2  | 0         | 25ms
          P1   | 0/0           | +0.00 | 0/2  | 0         | 38ms
          P2   | 0/2           | -1.00 | 0/2  | 0         | 40ms
          P3   | 0/0           | +0.00 | 0/2  | 0         | 37ms
总体：candidate 0/8  vs  mirror 2/8   => delta -0.250
镜像获胜座位：{"P0":0,"P1":0,"P2":8,"P3":0}
```

**两个结论，都是干净的**：

1. **座位偏向左证（用正确的确定性协议重测）**：四个座位全是启发式的镜像里，
   **P2 赢下 8/8 全部自然终局**，P0/P1/P3 **一局未胜**。
   所以上一轮"P2 7/7"不是未播种 RNG 的假象 —— 这个场景确实只有 P2 能赢。
2. **★ 第一个不受混淆的棋力读数**：把模型放进**唯一能赢的座位 P2**，
   它**两局都输**（胜者变成 P0），而镜像在同一个座位**两局都赢** → **delta = −1.00**。
   在 P0/P1/P3 三个座位，两臂都是 0 胜（这些座位谁都赢不了，无信息）。

**所以：在唯一可判定的座位上，模型严格劣于启发式（0/2 vs 2/2）。**
这是本项目第一次得到"模型本身更差"的、把座位与种子都控住的证据 ——
此前所有的 0% 都被座位混淆污染，无法区分。

`fallbacks = 0`（无静默回退），p50 25–40 ms。

**边界**：n = 2 个 seed × 4 座位 = 8 组配对，**样本很小**；delta −1.00 在 P2 上只有 2 对。
它足以说"在 P2 上模型没有表现出优于启发式"，**不足以**给出效应量。
下一轮应加 seed 数（每加一个 seed 约 +2 局/座位）。

## 任务 2｜SD 归档作为胜率/价值来源：**不成立**；作为行为测量：**可用**

（子任务产物：`v12/out/archive_value/{TASK2_report.md,winner_predictability.json,value_ceiling.json,imitation_mix.json}`）

### A. 胜者在**开赛前**就有 80% 可预测

| 口径 | 数值 |
|---|---:|
| 随机（按联盟数） | 35.58% |
| 简单规则"持 heuristic 的联盟赢" | 63.51% |
| 每场景众数（LOO） | 68.10% |
| **最佳赛前预测器（scenario + alliance index + has-heuristic，LOO）** | **80.26%** |
| **真正有信息的对局**（胜者 ≠ 策略预测 且 ≠ 众数） | **131/1003 = 13.06%** |

**即：87% 的对局在开赛前就能猜对胜者。** 这些对局无法教任何关于"怎么下"的东西。

### B. 价值标签的**天花板已经被常数预测器占满**

| 口径 | 准确率 | MSE | Brier |
|---|---:|---:|---:|
| **最佳常数预测器** | **0.802074** | **0.635005** | **0.158751** |
| 仅用 `policy` | 0.790266（**比常数还差**） | | |
| 仅用 `(rootFamilyId, playerId)` | **1.000000** | — | — |

- **`H(Y | seat) = 0.000000` 比特** —— 同一座位内标签方差为零，**信号不是弱，是根本不存在**。
- 48,714 行其实只有 **37 局 / 112 个座位 / 85 个有符号标签** = **每 573 行才有 1 个独立标签**。
- 仅 **987 行（2.03%）**来自有信息的对局，而且只来自**1 局**。
- `sign(valueTarget)` **100%** 等于"我方是不是获胜联盟" —— **原始终局结果逐步复制，无 shaping、无折扣**。

**结论：不要在这个池子上训价值头。** 若非要训，必须同时公布上面三个常数基线。

### C. 模仿学习：**两个老师完全交织，无法只模仿一个**

- `heuristic` 31,424 行（64.51%）/ `apk-like` 17,290 行（35.49%），**37/37 局里两者交织**，无任何按局/按轨迹的分隔。
- 动作**类型**层面两个老师差别很小：TV = 0.0948，用类型猜老师只比基线好 **+0.29pp**。
- **但在条件层面差别是绝对的**：**当"招募"和"攻击"都合法时，
  `apk-like` 选择招募 0/6,815 次（精确的零），`heuristic` 644/5,556 = 11.59%。**
  **只看边际份额会完全错过两个老师最大的行为差异。**

**结论**：可用于**测量两个老师各自的行为**（48,714 个带合法性集合的决策已端到端校验）；
**不可用于**"模仿某个指定老师"或"按结果过滤后的模仿"。

### D. 本轮新发现的**两个真 bug**

1. **392/1,395（28.10%）条记录 `winnerAlliance: null`**，全部是 timeout，且**全部**带
   `adjudicatedWinnerAlliance`（已验 1395/1395 等于 `argmax(finalArmyValueByAlliance)`）。
   **换用哪个标签是未定的，而它会改变目标分布**：heuristic 胜率 **75.27% → 55.13%**。
2. **池子里 27.75%（13,519 行 / 7 局）的 `valueTarget` 为 null，但归档里这 7 局都有终局胜者。**
   我核对了上游：`baseline_dataset.jsonl` 里**只有 30 条 `winnerAfter` 非空**（对应 30 局），
   **所以 T12-03 的转换器是对的，丢失发生在上游导出步骤**。修好它可以把 value 覆盖率从 72.25% 提到接近满。

### 3.5 三条方法学结论（都很重要）

1. **座位偏向方向逐图不同**（Duel/demo 强烈偏 P1；`teacher-eval` 残局偏 P0 4/4）
   → **不存在通用座位修正，每张图必须各自跑镜像对照。**
2. **v6 的 0/10 比原来以为的更强，不是更弱。** 镜像显示 P1 在**全启发式**对局里赢 87.5%，
   而 v6 harness **给每个模型 5 局 P1** —— **四个模型在"默认就赢"的座位上也没有赢下一局**。
   （保留意见：占位者从启发式换成模型后，政策×座位交互无法由全启发式镜像测出，
   所以这不能算完整的因果证据，只是方向性加强。）
3. 归档里 **"座位奇偶" 与 "种子奇偶" 是同一个变量** —— 这解释了为什么按座位与按策略做预测会互相混淆。
