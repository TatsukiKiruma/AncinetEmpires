### 2.1 关键更正：77× 预算**没有**转化为棋力

上表是**准确率**。历史上每个空间策略对 HeuristicAI 都是 **0/10**，所以准确率显然不自动换来棋力。
本轮用真实对局检验了这个转换（`v12/tools/eval_budget_model_vs_heuristic.ts`，新工具）：

```
arm=trained:v12/models/budget_s42.json  scenario=SDPLAN:sd-normal:(4) Crossroads.aem
game 1/4 modelSeat=P0 winner=P3 turn=33 steps=1324  [NATURAL]
game 2/4 modelSeat=P1 winner=P2 turn=31 steps=1093  [NATURAL]
game 3/4 modelSeat=P0 winner=P3 turn=22 steps=675   [NATURAL]
game 4/4 modelSeat=P1 winner=P2 turn=28 steps=1061  [NATURAL]
→ model wins 0/4; natural 4/4 (truncation 0%); natural win rate 0.0%
```

| 项 | 值 |
|---|---:|
| 自然终局 | **4/4（零截断）** |
| 模型胜 | **0** |
| 座位 | **P0、P1 都试过，都输** → 座位偏向解释不了 |

**所以：预算从 87 → 6,752 updates 提升了 7pp 准确率，却仍然是 0% 胜率。**
这与 T12-06 的发现互相印证：ΔQ 与启发式分数几乎不相关（ρ=0.108），
说明**信息不在优化步数里，也不在当前的监督信号里**。

**顺带测出的成本模型**：SD 分布上"模型 vs Heuristic"约 **30 ms/步**，4 局全自然终局约 3 分钟量级。
**这是廉价的** —— 与 T12-02 的 `planner_residual`（**9.9 s/决策**，一个 9 回合对局 22 分钟）相差两个数量级。
神经策略与搜索策略的评估成本完全不在一个量级。

详见 `v12/out/training/T12-01_strength_followup.md`（含 n=4 的统计力边界说明）。

### 2.2 诊断：不是"随机弱"，而是**系统性少招募、多攻击**

0% 胜率本身不可行动，所以我加了两个探针（`allowInteractiveFallback: false` + 逐决策记录）：

| 探针 | 结果 | 含义 |
|---|---|---|
| `totalFallbacks` | **0** | **推理路径正常**，不是静默回退成启发式（adapter 默认会静默回退，必须显式关掉） |
| p50 延迟 | 24–37 ms | 远在 1000 ms 契约内 |
| 与启发式同状态一致率 | **41.5%** | 既非随机，也远非"在模仿" |

**按动作类型拆开，失败模式非常一致（4 局同向）**：

| | move | **recruit** | wait | **attack** |
|---|---:|---:|---:|---:|
| 模型（game 2） | 28 | **5** | 10 | **21** |
| 启发式（同状态，game 2） | 30 | **24** | 7 | **8** |

**模型在相同状态上比启发式少招募 3–5 倍、多攻击 2–2.6 倍**；`move` 几乎相同，
说明**不是动作空间缺失，是主动不选招募**。经济型 4 人图里不造血 → 中盘崩，这就是败因。

**我尝试用训练标签解释，失败了。** 训练标签总体 RECRUIT 4.24% / wait 31.77%，
`heuristic` 老师 3.44%——看似支持"学了坏老师"。但按回合分桶后，档案里 `heuristic` 在 turn 0-5 招募 11.26%，
而我在**同样相位**实测到 24–45%，**相差 10–20 倍且无法用现有数据解释**。
所以**本报告不声称老师差**，只报告评测内部 apples-to-apples 的那个偏移。

### 2.3 干预实验：**我自己的因果假设被推翻了**

我提出并检验了一个便宜的可 falsify 假设：*只强制招募（其余全不动），胜率应当改善*。

```
intervention=recruit, totalInterventions=23（4/6/4/9）
game 1/4 seat=P0 winner=P2 turn=75 steps=3772  [NATURAL]
game 2/4 seat=P1 winner=P2 turn=43 steps=1777  [NATURAL]
game 3/4 seat=P0 winner=P2 turn=56 steps=2476  [NATURAL]
game 4/4 seat=P1 winner=P2 turn=30 steps=1128  [NATURAL]
model wins 0/4; natural 4/4 (truncation 0%)
```

| | 基线 | 强制招募后 |
|---|---:|---:|
| 干预次数 | 0 | **23** |
| 模型胜 | 0/4 | **0/4** |
| 终局回合 | 48 / 32 / 33 / 50 | **75 / 43 / 56 / 30** |

**干预确实生效**（23 次覆盖、对局长度被显著改变），**但仍一局未赢**。

→ **"少招募"是相关，不是原因。** 模型与启发式的差距是**分布式的**，不是单点缺陷。
这与其它读数一致：同状态一致率仅 41.5%、val 准确率 44% —— 模型整体就是"另一个更差的策略"。

**对 T12-08 的含义**：残差/门控架构不能指望靠"修某一类动作"取胜，
它必须在**整体上**证明优于启发式，否则就该退回到极少数它确实更懂的决策上。
本轮**排除了"单点修招募"这条捷径**，但没有为任何路线的可行性提供正面证据。

### 2.5 顺着混淆查下去，找到了**整个项目 0% 胜率的一个可能根因**

为了搞清楚 P0/P1 为什么系统性劣势，我去查了**归档本身**，结果是本轮最重要的发现：

**现象**：31 个场景里 **26 个只有 ≤2 个不同胜者**，多个场景**只有一个**：

| 场景 | n | 胜者分布 |
|---|---:|---|
| `sd-normal:(2) Liberty Port.aem` | 15 | **a1:15（100%）** |
| `sd-normal:(4) Solitude.aem` | 16 | **a1:16（100%）** |
| `sd-3p-normal-extra:(3) Midway.aem` | 22 | **a1:22（100%）** |
| `sd-normal:(4) Crossroads.aem` | 20 | a2:16 a3:4（**a0/a1 一局未胜**） |

**机制**：把 `policyByPlayer` 与 `winnerAlliance` 对上，1,003 条对局里
**胜者是 `heuristic` 玩家的占 75.27%**，`apk-like` 只占 24.73%。

**所以这些对局的胜负在很大程度上由预设的策略分配决定，而不是由棋力决定。**

**三个后果**：

1. **这很可能是长期 0% 胜率的真正解释。** 如果评估协议是"神经网络顶替 `apk-like` 座位去打 `heuristic` 座位"，
   它结构上就要输掉约 3/4 的对局，**与网络好坏无关**。历史"每个空间策略 0/10、0/40"与此完全吻合。
   我前几轮把这个 0% 读作"模型弱"，**至少很大一部分是协议造成的**。
2. **它污染了价值标签。** value 标签由 `winnerAlliance` 决定；胜者主要由策略分配决定，
   所以 value 学到的很大一部分是"这个座位是不是 heuristic 座位"。这解释了 T12-04 里
   `valueTarget` 的极端偏斜（**+1 占 80.2%**，4 人混战里本不该如此）。
3. **它反过来解释了 BattleSearchAI 为什么能出成绩**：它的 17/20 是在 `(2) Duel.aem` 上、
   两个座位各打 10 局的交替座位协议下取得的。
   **⚠️ 更正（见 `V12_FOLLOWUP_REPORT.md` §3.1）**：我原先说 Duel 的镜像基线是"2–2、无座位偏向"——
   **那是错的**，那个 2–2 只有 4 局。后续用全启发式镜像重测 Duel：**n=10 → P1 8/P0 2；n=8 → P1 7/P0 1**，
   **Duel 有很强的 P1 偏向**。**17/20 仍成立，但理由不同**：纯座位效应上界只有 10/20，造不出 17/20。

**因此：在评估协议修好之前，任何棋力结论都不作数。** 我此前基于 `(4) Crossroads` 的对局结论
（§2.1–§2.3）已全部撤回。详见 `v12/out/training/FINDING_seat_policy_confound.md`。

**下一步优先级**：① 修评估协议（镜像配对 + 交替座位 + 逐座位报告）；
② 重估 SD 归档作为**胜率/价值**来源的价值；③ 检查历史评估协议（v6 五图基准等）是否同样被污染。
