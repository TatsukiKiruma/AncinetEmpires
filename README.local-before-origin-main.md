# 远古帝国 AI 训练项目文档入口

本文档是根目录文档入口。`demo` 目录下的文档属于示例工程自身说明，本次整理不修改 `demo/README.md` 和 `demo/plan.md`。

## 项目定位

本项目用于复刻《远古帝国》的核心战棋规则，并把规则引擎逐步硬化为可用于自动对战、MCTS、遗传算法调参和强化学习训练的环境。当前重点不是直接训练模型，而是先保证规则确定、动作合法、状态可克隆、接口可批量运行。

主要代码位于：

- `demo/src/game`：规则引擎、地图、单位、AI、训练环境封装。
- `demo/src/game/env.ts`：Gym-like 环境入口。
- `demo/src/App.tsx`：手动沙盒和演示 UI。

## 当前本地实现摘要

基于 2026-06-19 对本地文件的阅读：

- 已有 16 类正式地形和 20 个正式兵种配置。
- 已有结构化 `Action`、`GameEngine`、合法动作校验、深拷贝状态和 Gym-like `AncientEmpiresEnv`。
- 已有状态、墓碑、经验、部分光环、治疗、召唤、支援、修理、破坏和突击二次移动的规则实现。
- 随机 AI 与启发式 AI 已存在，训练环境可返回动态合法动作和 action mask。
- 本地代码仍使用旧的单一 `recruit` 动作，尚未实现目标规则中的 `recruit_to_castle` / `recruit_and_deploy` 拆分。
- 本地 `GameState` 尚未包含 `pendingUnitId`，招募后强制新单位先行动的机制仍待实现。

## 近期原则

- 文档中的“目标规则”和“当前实现”必须分开描述。
- AI 训练接口不能依赖 React UI 的两阶段交互。
- 所有训练路径都必须经过合法动作生成和校验，不能使用测试专用绕过。
- 规则引擎中不应引入不可控随机性；需要随机时必须支持 seed 或注入 RNG。
