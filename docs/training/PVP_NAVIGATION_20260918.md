# 真人回放补训与 v4 路径特征（2026-09-18）

已完成当前引擎严格回放、8 组各 3 轮训练和 8 worker 的 120 场实战。原模型与默认 AI 保留。

78 局均通过文件哈希、动作合法性、记录数和最终胜者校验；其中 43 局提供真人胜方标签，其余胜方为机器人槽位。本轮为抽样对照，真人训练/验证/测试分别为 31/7/5 局、1123/262/235 条动作。AI 对照训练使用 8437 条样本，不是原 886494 条数据的全量重训。

| 模型 | 常规自然胜 / 8 | 优势残局自然胜 / 12 | 超时 / 20 |
|---|---:|---:|---:|
| 原始全量 v3 | 0 | 6 | 2 |
| 纯 AI 样本重训 v3 | 0 | 8 | 2 |
| 真人 10% v3 | 0 | 4 | 5 |
| 真人 25% v3 | 0 | 3 | 5 |
| 真人 10% v4 | 0 | 6 | 4 |
| 真人 25% v4 | 0 | 7 | 3 |

所有实战非法动作、停滞保护、步数保护均为 0。胜率排除超时裁定胜。

真人最终留出命中率：原模型 16.60%，v3＋25% 为 26.38%，v4＋25% 为 28.09%。仅依据验证集选出的候选为 fresh-v4-p25：4096 维、学习率 0.1、label、teacherWeight=0、平均权重，第 3 轮。真人占比 25% 是采样比例，单样本权重为 1，不是 teacher 权重。当前低学习率 0.03 续训方案的留出命中率较低；不能推断其他续训设置一定无效。

结论：v4 比相同真人占比的 v3 更好，但本轮仍未超过纯 AI 数据实战对照。暂不扩大真人补训或追加 epochs。新特征版本单独重新训练、另存模型；进一步优先处理长期目标稳定和收官成果标签。

实现：新增 tools/skirmish_navigation_features.ts，以反向多源 Dijkstra 描述敌方城堡、收入点和可攻击位置的可达性、移动回合及路径推进，复用单位移动规则与单 observation 缓存。保持 v3 特征语义；v4 需要完整 observation 重导出。新增兼容性检查和来源哈希的 --initial-model，更新导出 CLI 与生成器指纹。

工程验证：类型检查、441 项测试、构建通过；54 条样本 / 2026 个候选在线离线特征逐项一致；120 局原始日志、模型/数据哈希和配对初始状态全部核对通过。
