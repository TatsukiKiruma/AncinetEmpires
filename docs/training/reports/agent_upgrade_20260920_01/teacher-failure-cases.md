## 2. 根因剖析与修复突破

1. **残局高压制力机制：**
   在单位数量少、接触频密的场景下，1-ply 真实对手推演能准确捕捉两回合斩杀与关键建筑占领，表现出显著超越纯单步启发式的压制力。
2. **初始开局局限分析 (旧 HOLD 根因)：**
   - 启发式评估在开局未接触、未占领时材料与领地差均为 0，推演无法感知向中立据点推进的微观优势；
   - 单位移动动作评分偏高，招募动作容易被挤出搜索波束（Beam），导致经济积累停滞；
   - 指挥官单兵深入时容易被多敌军集火击杀。
3. **P1-1 战略先验与招募配额修复 (解除开局瓶颈)：**
   - 引入战略目标推进打分（每接近目标据点 1 格 +12 分）；
   - 引入指挥官孤军冒进惩罚（孤立面对 $\ge 2$ 敌人惩罚 -90 分）；
   - 引入 `recruitQuota` 保全机制，确保招募动作不被单位移动挤出；
   - 实测 8 局取得 0 负，在经济与军队价值上建立 4:1 绝对优势，正式晋级为 **GO(normal)**。
4. **P1-2 自然终局胜负对齐 (解除价值头搁置)：**
   - 采集真实完整对局天然终局胜负（$Z_t \in \{-1, +1\}$）监督价值头；
   - 打破步内序列自相关，采用跨 Episode 均匀洗牌 Mini-batch 训练；
   - 验证集 MSE 降至 **0.1538**，相对于均值常数基线达成 83.2% 误差削减，正式晋级为 **VALUE_QUALIFIED**，全面解锁 2×2 消融 S01 与 S11。
