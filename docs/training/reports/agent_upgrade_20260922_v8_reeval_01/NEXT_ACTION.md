## 2. 轨迹行为分析与归因解释

### 2.1 空间模型（SPATIAL_V2 / SPATIAL_DAGGER）
- **接口调用恢复正常**: 空间张量（9600 维）、全局特征（20 维）及候选语义（32 维）全量且正确地注入前向网络，单步推理平均耗时约 25.5ms，严格满足 1000ms 硬看门狗要求（P99 ≤ 33.2ms，零超时，零非有限值）。
- **棋力实况**: 正确调用旧权重后，纯神经策略在长线实战中录得 0 胜。分析对战轨迹发现：旧权重（仅在 v7 小规模 ~2k 样本上训练两轮）在微观战术上有占点和移动倾向，但缺乏全局战线协同与防守纵深意识，经常将指挥官孤军冒进送入敌军集火范围。
- **重招募表现**: 虽然总胜率为 0，但 SPATIAL_V2 的重招募成功率达到 93.8%（15/16），证明其在城堡恢复逻辑上已具备基本反应能力。

### 2.2 先验引导搜索（S10）显著弱于纯搜索（S00）
- **客观现象**: 在相同预算（节点 20，软限 200ms，硬限 900ms）下，纯搜索 `S00_SEARCH` 获得 6 场自然胜（胜率 46.2%），而加入空间先验的 `S10_SPATIAL_SEARCH` 仅获得 1 场自然胜（胜率 6.7%）。
- **深度归因**:
  1. 现存 Spatial 模型的先验打分质量较低；
  2. S10 的候选筛选逻辑将空间先验 Top-K 动作纳入搜索队列，排挤了原本启发式中的关键战术动作（如关键卡位、残血撤退）；
  3. **结论**: 不成熟的神经网络先验正在对有限预算的搜索造成**负向干扰**（Negative Prior Bias）。

### 2.3 评测协议修复的有效性
- **单位数不变截断已彻底移除**: 如 Liberty Port 对局（Seat 1, Seed 42）持续博弈至第 24 轮、第 789 步自然打破僵局取胜。如果在旧协议中，该对局早在第 50 步前就会被“单位数 25 步不变”腰斩。
- **截断诚实分类**: 仅保留 `TRUNCATION_MAX_STEPS`（800 步）和 `TRUNCATION_MAX_TURNS`（45 轮），未被伪装为胜负或平局。
