## 3. 结论

1. 上一轮" S10 空间搜索 45% W/N、四臂最高"的结论**不能维持**。在更强对手回应下 S10 降至 25%，
   低于 HEURISTIC（30%）与 S00（30%）。
2. S00 由 35% 降至 30%，降幅较小；S10 由 45% 降至 25%，降幅最大。
   这与"先验引导的搜索更依赖对手弱回应才能奏效"一致，也说明此前的优势部分是弱对手模型造成的假象。
3. n=20/臂，Wilson 区间高度重叠，**任何两臂之间都不构成显著差异**；本轮同样只作为开发诊断，
   不作为棋力结论。
4. 两个搜索臂在全部 20 场中都出现过软预算（200ms）超限（wallClockExceededMatches=20），
   硬上限 900ms 未被突破（p99 均 < 360ms，max < 650ms）。
