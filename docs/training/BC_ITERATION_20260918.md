# 2026-09-18 BC 诊断与迭代验证

本轮已完成：7组小规模训练对照、176局新实战/快照回归，所有实战阶段均为8 worker。未替换游戏默认AI。

## 主要结论

- 原模型与BC-blend在相同48局上：正常开局自然胜从0/24升至9/24，优势残局自然收尾从9/24升至17/24，但回合超时从5/48升至9/48。
- 平均权重改善了抽样验证命中率，但纯BC重训方案正常开局仍为0/8；128条定向补数据在另两张地图也未改变胜负数量。
- 96个决策点的实时/导出特征一致；64候选采样改变8个选择。教师评分缺失不是问题；6222条验证样本中只有7条标签低于最高教师分，另有220条同分替代动作差异。
- 后期高价值移动被强制结束回合的现象已复现，并添加可选实验参数；8对快照续局仍全部超时，因此默认不启用。
- 类型检查、435项测试和构建通过；176局非法动作和步数保护停止均为0。

## 新增能力

训练器支持 `--save-epochs`、`--select-best`、`--average-weights`。默认保留原行为；只有显式选择才使用平均权重或最佳轮次。验证工具默认8 worker，支持动态任务队列和按回合进度。

`createBcBlendPolicy` 的可选参数 `preserveProductiveLateMoves: true` 仅用于后期规则实验，尚未证实能改善终结能力，不作为推荐默认配置。

## 后续方向

优先研究路径可达性、推进目标和更广泛的失败状态纠错；不建议仅增加epoch、切换mixed或大量复制同分布数据。新的特征版本必须重新导出对应特征，不混用旧特征文件。BC-blend可保留为对照候选，但还没有全面超过启发式AI，收尾超时仍需处理。
