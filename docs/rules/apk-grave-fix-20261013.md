# APK 同格墓碑覆盖修复（2026-10-13，r4）

## 已确认的问题与修复

真实对局 dfe18a 在 (11,12) 的墓碑首次状态分歧发生于 **记录索引 3735**（从 0 开始）。此前索引 3660 生成计时玩家 P1、剩余 1 的墓碑；3735 又有单位死在同一格。APK 将该格改写为计时玩家 P4、剩余 1。项目 `createGraveAt` 遇到同格已有墓碑便直接返回，错误保留了旧的 P1 计时信息。

因此旧项目在 3779 将其减至 0，在 3905 删除；APK 则在 3845 按 P4 回合减至 0，直到 3957 才被进入该格的人鱼消耗。人鱼受到墓碑 10 点伤害后剩 90 HP，4037 被龙的 90 点伤害击杀，4121 的移动目标格因此为空。

现在同格新增死亡会刷新已有墓碑的 `ownerId` 和 `remainingTurns=1`。保留内部墓碑 ID，避免创建重复格记录。没有修改合法动作、占位、伤害、水上恢复、回合顺序或回放容错。
