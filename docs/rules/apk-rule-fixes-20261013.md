规则版本：`apk-4.2.5.1-rules-20261013`。目标 APK 为 `aer-release-4.2.5.1.apk`，SHA256：`51B00185F300DD8899284AA91986AEE9A1CC73FA012262A0D9EEBC97FAD1AA7B`。

本版修复已确认会影响 SD/SO 遭遇战训练的规则差异，附带原生 AI 机制信息与两个项目规则策略。它是独立的无界面环境，不包含训练历史、模型权重、APK 解包目录或账号配置。

## 已修复的规则

| 项目 | 本版行为 |
| --- | --- |
| APK 地形数据 | 按对象空标记、变长数组和真实字段顺序读取；84 项 kind 与移动字段通过独立资源对照，单位段边界为解密载荷偏移 3373 |
| 水域与地形能力 | t0 普通单位进入成本 3；石人在 t2 水域成本 3 且无山地加成；狼射手在 t17 山地成本 3 且无森林加成 |
| 大地之子 | 陆地成本 1，非陆地成本为基础值加 1；普通水面为 4 |
| 移动覆盖 | 只按 APK 地形 kind 查找正值覆盖，不把贴图 ID 或项目 terrainId 当成 kind；自定义地图需明确提供 APK 类别才能使用此覆盖 |
| 地形转换 | 破坏、修复和转换同步或清除旧类别、陆地及成本覆盖，避免沿用转换前的数据 |
| 致盲 | 射程归零时禁止邻格治疗和召唤；亡灵目标也不能绕过治疗候选范围，自身治疗例外仍保留 |
| 召唤经验 | 骷髅继承召唤等级及其累计经验阈值，例如 1 级从 100 经验开始 |
| 满级经验 | 达到配置等级上限后不再获得正经验 |
| 同盟占领 | 己方和盟友建筑均不生成占领动作 |
| 淘汰清理 | 自然淘汰、投降和 SyncDestroyTeam 共用领地中立化与单位移除；正常战斗死亡事件先结算，保留指挥官死亡计数 |

公共动作由 `getLegalActions` 生成，`GameEngine` 验证并结算，`AncientEmpiresEnv` 复用该引擎。回归覆盖修复反例、动作编码与 mask、克隆、首回合收益以及官方地图和回放显式地形入口的一致性。

## 回放证据的边界

`validateApkReplay` 继续兼容 APK 无效命令的空操作展开，但现在返回 `evidence`，包括跳过、替换、招募坐标推断的原因、记录索引和数量，并明确标出 `validationBypassed`、`fullyConsumed` 与 `apkStateCompared: false`。

设置 `rejectInformationLoss: true` 可拒绝这些信息损失及未完整消费的输入。原仓库命令行工具对应选项为 `--reject-information-loss`。无论此选项是否开启，执行成功都不等于 APK 每一步 HP、金币、经验及终局状态已经做过实机差分。

## 包内 AI

- `HeuristicAI`：项目启发式评分基线。
- `ApkLikeAI`：参考 APK 单位调度的近似基线，仍使用项目评分。
- [APK 原生 AI 信息](apk-native-ai.md)：记录 APK `C1275a` 的调度、目标和招募机制，源码证据及尚未恢复的控制流。

原生 AI 信息不等于原生算法完整移植。包内没有宣称这两个项目策略与 APK 原生 AI 逐动作等价。`npm run smoke:ai` 验证两个基线各自连续执行，不能替代实战胜率评估。

## 使用和兼容性

在新目录解压后执行 `npm ci`、`npm run lint`、`npm test`、`npm run build`、`npm run smoke` 和 `npm run smoke:ai`。不需要原仓库、Android 设备或本地 APK 资源。

`DELIVERY_MANIFEST.json` 保存规则版本、每个交付文件的 SHA256 和策略身份。历史模型与样本应记录旧规则版本；本版改变合法动作和结算，不能把旧模拟器产生的状态标签直接当作本版真值。升级后应重新评估模型，保留历史文件以便追溯。

地形 `kind` 与兼容字段的数值已校正；`APK_TERRAIN_RECORD_SIZE` 为 `null`，表示记录变长，不可再用固定跨度读取资源。环境地形快照增加了 `isLand/capturable/variants/graphicsType`，数组为独立副本。外部读取原资源时应使用对象协议，不能按 40 字节索引。

默认训练范围是正常遭遇战。战役剧情、任意 mod、单人难度减伤及原生 AI 完整决策等不在本版等价承诺中；本版没有完成 Android 实机逐状态穷尽验证。环境的截断代理奖励与自然胜负继续区分，详见[环境接口](../environment/interface.md)。
