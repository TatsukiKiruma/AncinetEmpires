## 运行

在项目根目录安装依赖后：

```text
node ai_training/run.mjs --prepare
node ai_training/run.mjs node --import tsx tools/skirmish_training_runner.ts --help
node ai_training/run.mjs python python/verify_parity.py --help
npm --prefix ai_training run lint
npm --prefix ai_training test
```

历史命令中的 `v19/...`、`python/...`、`tools/...` 和 `training_runs/...` 均相对本目录。命令行参数是否支持 `--help` 以具体工具为准；不能随意执行无帮助模式的旧实验脚本。

启动器只准备指向主项目公共代码、APK、回放和依赖的目录链接，然后运行指定命令，不自动启动任何实验。链接未纳入 Git，换机器后重新运行 `--prepare`。

Python 解释器必须安装所需的 PyTorch 等依赖；PATH 中的 `python` 不一定是之前使用的训练环境，可将解释器完整路径直接传给启动器。各脚本对解释器环境变量的支持以其说明为准。

完整应用保留已有策略与已发布模型；独立研究应使用公共导出工具生成的环境副本，不把整个 Git 仓库或本目录交给需要从零设计方案的人。
