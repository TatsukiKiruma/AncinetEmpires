# BattleSearchAI框架纯模型化映射

依据公共`src/game/ai/battle_search_ai.ts`移植控制流程，源身份见`search-purity-gate.json`。公共文件保留不动；实验实现在`model_battle_search_ai.ts`。由于公共构造器硬编码启发式依赖，实验版本移植其流程而不实例化公共类。

|公共框架环节|实验实现|
|---|---|
|默认基础策略与候选排序|分层Policy默认动作；联合路径概率稳定Top6，默认动作始终在候选中|
|默认叶子缓存`leafByIndex/leafOf`|按根候选缓存完整Maximin评估|
|必胜直取|引擎自然终局胜利±4主导，保存已验证己方连动|
|`friendlyRolloutSteps`|最多3步，每步重新使用分层模型从合法非end候选中选择，与原框架的非end连动范围一致|
|对手原单原子回应|actor/指挥官三敌军集火见证、权威movingThreat补充、对手策略候选；移动回应继续探测同单位合法攻击|
|Maximin|在已探测合法对手分支中取最低叶子，预算不足的根候选不参与接管|
|静态局面公式|冻结Policy上下文上的独立Value头＋实际结算净损血、敌指挥官减少与敌城堡占领|
|Takeover/Veto|大优间隔0.08；危险线−0.5或实际指挥官/关键actor损失，避险间隔0.03|
|随机抖动|移除；采用稳定候选顺序和固定节点预算|

整局2400/单步48搜索节点；单步30秒、整局600秒，2000实际动作。预算耗尽保留分层Policy默认，不调用启发式。跨原子连动须匹配完整预测状态及当前合法集合；不匹配即丢弃并重新搜索。

这是有界候选和有界回应上的Maximin，不声称穷尽敌方整个回合的所有排列。集火见证最多三个不同攻击单位，移动和攻击均经权威引擎执行；单个敌军最大伤害与多敌军累计净损血分别保存。
