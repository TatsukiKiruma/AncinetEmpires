## 2. 被推翻或被收窄的解释（不要再引用）

1. **「B1e 的 train 81.7% vs val 29.7% 说明教师目标泛化失败」——不成立。**
   实际送入 trainer 的 B0/B1/B1e/B0h_beh 四份文件，验证分区的输入序列与目标序列哈希**完全相同**
   （`inputSequenceHash=71aa9917…`、`inputAndTargetSequenceHash=9eaf6d5d…`），
   验证行 5,316 行**全部来源 h0**、`teacherActionCode` 出现次数为 **0**。
   也就是说 B1/B1e 的 val 衡量的是「在 H0 状态上对混合 H0/L1 目标的一致率」，**不是 B100 保真度**。
   不同策略、不同分布的两个数不能直接相减。（`v17_validation_audit_20260927.json`）

2. **「B0 训练用 L1 标签，val 就是一个纯净的 L1 模仿率」——不成立。**
   同一验证分区里 4,770 行没有 `targetSource` 标记，构建器把**实际行为动作**写进了 target；
   实际 target 与 L1 相同只有 4,542/5,316（≈85.44%），与行为动作相同 5,263/5,316（≈99.00%）。
   `~45% val` 因此不是单一来源的模仿率。

3. **「B1e_best 是教师验证最优检查点，它 0/20 说明教师目标下没有更好的检查点」——不成立。**
   `B1e_best` 是由上述 H0 验证指标选出来的，不是教师验证指标选出来的；补测它只排除了那一个检查点。

4. **「近似平局 / 结构不是瓶颈 / 只差更多算力」——过度推断，收窄为假设。**
   模型 logits 接近只说明**模型难以区分**，不说明真实行动价值接近；
   训练集可拟合到 94.8% 只说明**能记忆训练点**，不说明全图关系、寻路、协同决策的表示能力足够；
   报告里 top1−标签 logit 中位差 0.148 还包含 575 条答对且差值为 0 的样本，不能当作错误样本的中位差；
   2→4 blocks 无收益不等于 GAP 或其他全局信息通路无效，且四层版本不是保函数不变的初始化。

5. **「对 5 个败局替换首次分歧的一手没有翻盘 ⇒ 这些动作等价」——不成立。**
   只排除了这 5 次具体单点干预，既不证明动作等价，也没排除其他关键手或多步纠错。

6. **「验证 val 更高而实战更差 ⇒ 模仿准确率与棋力普遍反向」——不成立（数据缺陷导致的偏差）。**
   同一实际验证分区已完成玩家回合 0–2 只有 **2 行（0.038%）**，3–7 有 953 行，8+ 有 4,361 行（82.04%）；
   学生与 B100 来源均为 0 行。去除重复输入是正确修复，但开局在确定性地图上高度重复，
   去重后开局覆盖几乎消失。纯 H0 数据训练更贴合 H0-only val、却更不适应学生犯错后的状态，
   足以解释部分「val 更高实战更差」。
   价值验证同样没有 0–2 阶段（606 行、38 family），因此**开局估值与候选分支排序尚未被证明可用**。

7. **「界面上试玩很差 = 实验冠军很差」——不成立。**
   `src/game/ai/spatial_neural_adapter.ts` 默认从 `src/game/ai/models/` 载入三个内置模型，
   其 SHA 与解析后 JSON 都不同于 P1:s2026，也都没有冠军声明的 `encoderSchemaId`；
   arena 是通过 `--model` 显式加载实验权重的。
   T18-00 已把该映射写进 `identity/manifest.json#uiPolicyMapping`，当前结论
   `championIsBundledByDefault=false`。**本次没有替换界面权重**（还没有合格的新模型）。

8. **「启发式分数可以直接当 soft 目标或胜率/Q」——不成立。**
   L1 的分数来自带随机扰动的启发式评分，不是胜率也不是真实 Q；
   旧 `diag_v17_l1scores_scale.py` 对比的是 `targetActionIndex`（大多数是行为动作），
   它得到的 16.3% 不一致混合了「双次评分」和「标签字段混用」两种问题。

## 3. 本轮新增的工程合同变化（T18-01）

- 新版 L1 标签器（`L1_heuristic_singlepass_v18_1`）用**同一次评分**产生 `scores` 与 `chosenActionCode`，
  并定义稳定平局规则；旧版本 `L1_heuristic_isolated_v15_1` 的语义**保持不变**，旧数据不重写。
- 监督行显式携带 `targetPolicyId / targetVersion / targetActionCode / targetActionIndex / labelEvidenceKind`，
  并强制校验「索引指向的候选动作码 == targetActionCode」。
- 同一批冻结验证状态上分别记录 L1 与 B100 目标；教师模仿指标只按对应教师计算，
  H0 保真度另报，禁止把二者 train/val 相减。
- 未见输入验证集与「共享开局回归集」分开标记；后者允许与训练共享，**只能用于回归**。
