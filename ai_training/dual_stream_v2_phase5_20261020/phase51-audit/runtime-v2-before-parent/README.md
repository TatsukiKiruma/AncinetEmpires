# 双流 v2 阶段 1 运行时契约

入口为 `encodeDualObservation(state, legalActions)`。模块只依赖公共游戏代码，没有训练目录、模型、候选引擎模拟或应用接入。`legalActions` 必须是当前状态的完整权威集合；投降在因子化集合中屏蔽。

用户在本阶段确认扩展到最多 **6 玩家**，以容纳全部真人来源。当前常量为 `PLAYER_SLOTS=6`、`MAP_CHANNELS=34`、`ENTITY_DIM=66`、`RELATION_DIM=16`。2～4 玩家局面使用相同形状；空槽 active 为零。地图保持真实 H/W，不填充或裁剪到 32。实体长度由真实实体数决定，不设 140 的上限。

## 内存与索引

|数组|形状|顺序|
|---|---|---|
|spatialTensor|[34,H,W]|通道优先，Float32|
|entityTokens|[N,66]|先存活单位、再友方城堡、再墓碑|
|relationalBias|[N,N,16]|i、j、关系通道|
|playerOrder.features|[6,11]|顺位槽、特征|
|actions.pointers|[A,5]|Int32：actor、tile、head、class、target|

`contract.ts` 的字段名数组与 `ENTITY_FIELDS` 是唯一字段表。单位和墓碑用自身 ID 定位；城堡使用地块索引；end_turn 的专用 actor=N、tile=-1，不向实体流塞入空白地形或全局伪实体。堆叠新兵与指挥官是两个独立 token；空间格以 pending 新兵优先。城堡 token 表示仍属活跃友方的生产建筑，当前金币或占位不足不会删除建筑身份。

顺位使用 `getTurnPlayerIds` 的真实数字 ID 轮转顺序。当前玩家固定槽 0，其他活跃玩家依次排列，已淘汰但仍启用的参与方排在其后、active=0；禁用方不参与价值分布。delta_turn 除以 5，inactive 为 -1。金币/军力除以 10000，数量除以 100，预备役等级除以 9；不截断真实大军数量。

## 空间通道

0 地形类别（17 类编号/17）；1 权威地形防御/20；2～4 士兵、人鱼、幽灵移动消耗（上限4后/4）；5 建筑存在；6 自己建筑；7 盟友建筑；8～12 敌方顺位1～5建筑；13 中立或无槽建筑；14 受损城镇；15 墓碑存在；16 墓碑剩余回合/10；17 单位槽（slot+1）/6，空格0、无槽-1；18 自己1、盟友0.5、敌方-1；19 有效HP比例；20 `(2*level+!hasActed)/20`，可无损拆出等级与行动位；21 权威指挥官标志。

22 下家敌方最高伤害；23 该敌方不同可攻击者数；24 全部敌方不同攻击者前三伤害和；25 减益位图（致盲1、虚弱光环2、召唤潜力4）；26 友方最高伤害；27 友方前二伤害和；28 友方远程覆盖数；29 鼓舞光环；30 净化光环；31 治疗潜力；32 德鲁伊支援潜力；33 咽喉1/前线2位图。

伤害基准是100HP、0级、无状态的权威士兵，数值除以100，可大于1。单位按兵种与真实障碍获取可停留格，再按权威射程投影；每个攻击者在每格只贡献一次最高伤害。伤害调用 `calculateDamage`，共享近战/远程与地形属性缓存，不写另一份伤害公式。当前行动方已移动者不能重新获得移动，已行动者不计本次攻击潜力；未来其他行动方使用当前生命和状态、可重新行动的静态假设。己方pending锁受现行规则约束。

静态潜力图不预测未来回合初的回血、状态衰减、伤亡和占位变化。召唤位表示女巫射程潜力，光环/治疗/支援通道表示可达区域；对具体目标的限制以实体关系和权威合法动作mask为准。当前引擎没有指挥官攻防光环、水晶治疗光环或冰元素冻结机制，因此不凭空增加这些能力。咽喉用步兵低消耗四邻域识别，前线用双方控制区交界识别。

## 实体关系与动作

实体兵种为21维one-hot；状态4通道以 `1+remaining/10` 同时区分存在与0回合状态。HP使用有效上限，军力使用 `calculateArmyValue` 的单实体/零金币投影。坐标同时保留原值、除以W-1/H-1的绝对坐标、相对己方指挥官（没有则棋盘中心）且除以W/H的坐标。

关系通道见 `RELATION_NAMES`。路径使用公共 `TacticalPathfinder` 的真实最短移动代价，8以上同桶、不可达另有明确mask；路径终点可为敌方占位，但不穿过敌方。直接attack/heal/support来自定向权威查询，移动后攻击和静态伤害从同一次可达扫描查表。光环关系表达当前位置到目标的范围和状态条件，最终是否可提交仍使用动作mask。

当前权威 `Action` 有14种类型（含投降），非投降13种。语义头15个编号包含投降保留位，以及区分 `destroy_town` 可选target字段的独立头；这不代表权威有15种动作类型。招募兵种和目标引用独立存储，指针不依赖候选顺序，decode不保存原动作对象。稀疏条件mask通过actorMask、tilesByActor、rowsByActorTile表达，无须分配 `[N,H*W,所有语义]` 稠密数组。

## 价值与使用边界

`encodeOutcomeTarget` 接受观测前态槽映射和已证明的原生赢家联盟。赢家联盟成员均分质量；规则平局在活跃参与方均分，同时全灭则在原启用参与方均分；未知结果或valueMask=false输出零向量及false。`aggregateAllianceValue` 按观测槽0的联盟求和。截断、代理奖励、投降或真人重建终局不能自动生成自然结果标签。

完整阶段证据位于 `ai_training/dual_stream_v2_phase1_20261020/`；公共模块禁止反向依赖该目录。阶段2～5未实现、未训练、未启动自对战。
