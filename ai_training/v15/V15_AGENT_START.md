## 2. 分工派发附加指令

以下每段附在完整启动指令后使用；接收者仍需理解共同契约。

### A：协调与评测

你负责 T15-00、T15-09A/B/C、T15-11。维护协议/root 清单、运行身份、评测/聚合/打包工具，不修改其他负责人的训练/编码实现。先使 GE 可用，模型产出后按相同面板评测。由原始数据核验消费和结果，不自行替训练负责人挑确认集上最好的模型。

### B：规则与编码

你负责 T15-02，以及 Python/TS schema 公共接口。修复升级经验先于反击的投影顺序，保持引擎规则，明确 V13/V14/V15 状态和候选语义。拥有任务书列明的 rules/encoder/shared policy/predictor 与 Python 模型 schema 文件。向 F 提供 golden 与接口，向 C/E 提供冻结 schema；不要并发改训练循环或标签器。

### C：训练与实验运行

你负责 T15-03、T15-06、T15-08 的训练部分及消费验收。修复总更新退出、final/state、恢复和按 update 调度，支持确定性来源配额 sampler。收到 E 的冻结池后完成三 seed 基线和九条 D 运行。不要改变 B 的 schema 或 D 的标签规则；对负结果同样完整报告。

### D：状态、标签与规则归因

你负责 T15-01、T15-07、条件 T15-10。实现精确恢复与独立 L1 标签器，证明 query 开关不影响行为轨迹；在真实窗口做有限反事实。按预算推进回合/联盟感知教师，不以其资格未通过阻塞主线。生产 H0 RNG 保持冻结。

### E：数据与对照池

你负责 T15-04、T15-08 的采集和匹配池。实现不含标签/候选顺序的真实模型输入去重，按来源家族分区，逐个重评历史 best/last。调用 B 的统一编码与 D 的标签器。C2-42 final 冻结后建立 D1/D2，按唯一新输入和层配额匹配，交付 C 可核验的采样清单。

### F：数值和导出验证

你负责 T15-05。核验新 schema 的 TS/Python 输入/前向、tie-break、候选重排梯度/一次更新及导出真实推理路径。负责独立验证工具和必要的 parity 加载器接口；发现公共实现错误交 B/C 修复。运行一次有上限的真正 128 训练状态回归，不把它推广为正式训练最优参数。
