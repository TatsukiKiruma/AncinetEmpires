# 数据复用与规模验证执行计划

用户于2026年10月3日授权继续后继任务，覆盖此前暂停及只分析要求。本轮从已完成诊断继续，不重复旧160场DEV或失败搜索实验。正式冠军和16/20纯模型验收口径保持不变。

1. 实算旧BC、UI、P1与θ1的权重身份，确认纯策略加载入口及已有可比证据。
2. 盘点本地原始对局与2500局哈希数据归档的对应关系。特征归档完整不等于原始状态完整；不从不可逆哈希伪造棋盘。
3. 对本地原始归档执行50局分层兼容性试验，使用现行权威引擎，核验初态、合法动作、动作编码、reward/done/winner。保持原始规则与旧文件不变，失败样本隔离并记录原因。全局预算先设10分钟，逐局最多120秒；预算未完成必须如实报告，不把前缀通过写成全局通过。
4. 若严格重放门槛失败，定位是否初态收益变化、动作/规则变动或缺少快照，区分历史复现与当前训练可用性。不得关闭校验来凑训练量。可以利用现行规则兼容的保存状态重新标注，但必须以独立迁移数据身份验证。
5. 对通过兼容性门槛的来源，构建小型当前schema重编码样本并验证候选顺序、schema、身份与家族隔离；明确已存档局数、可恢复局数、独特棋盘和真正入训行数。
6. 数据合格且数量足够后，冻结同架构、同目标的嵌套规模对照；先建立可复现小档，不能把反复抽样次数当作数据扩量。若旧归档不可用，按失败证据选择新的现行规则数据来源再推进。

当前输出独立保存在 `v19/out/data_scale_20261003/` 与 `v19/review/data_scale_20261003/`。全过程不覆盖历史证据、不修改H0、不启动CONFIRM追分。训练和正式评测是否进入下一阶段由真实兼容性与监督质量结果决定。

## 实测后的执行调整

- 现行工厂50局只有10局通过；独立历史适配器首轮49局通过、1局预算超时，该局以600秒预算完整复核通过。恢复50局不是证明本地1395局全部可恢复。
- 50局共抽取1600行，只有320行属于正式五图双人场景；它们作为历史课程回归池，不承担本轮主扩量训练。
- 现行规则原始轨迹实际存在54622行、140家族；其中new_train有34530行/75家族，new_val有14283行/50家族。固定每家族12个状态，重编码为900行训练候选与600行回归候选，再做真实输入去重。它们均为历史已消费来源，不是独立sealed证据。
- 三档主实验按五图均衡家族前缀扩大现行规则训练来源，固定模型θ1（34/20/53、2 blocks）、硬CE目标、禁用value、学习率1e-4到1e-5。比较相同128次更新与约4次每行曝光两种预算，记录真实优化消费。每档保存四分之一、二分之一和最终检查点。
- 本轮离线结果只用于选择后继数据策略，不直接晋升、不改冠军、不据此声称16/20。若小档覆盖或回归门槛不足，先修数据或预算再扩大，不因样本数变多盲目启动完整arena。
