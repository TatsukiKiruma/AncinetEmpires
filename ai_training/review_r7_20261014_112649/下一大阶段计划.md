### WP1 可信runner、编码和恢复合同

依赖WP0。研究适配层调用冻结GameEngine/Env/getLegalActions，不能修改其判定。

- 将每局/策略放入可终止进程或worker；父进程以单调时钟监督，策略死循环不能卡住裁判。每步候选1000ms安全上限、每局300秒、3000引擎步，六历史策略和模型一视同仁；若硬件探测证明1000ms正常开销不适用，只允许在所有正式DEV之前统一重新冻结上限及原因。timeout记截断、异常记error，进程树回收可验证。
- 策略只收到状态及候选的独立副本；裁判保存原始不可变候选码集合。检查返回动作、step.info/done/reward、真实状态转移；非终局空合法集为error。对合法surrender保留正常执行，分类为投降终局，不在推理时删候选或改选end_turn。
- gameplay重复key从实际类型和规则读取字段推导，覆盖支援/治疗标志、remainingTicks、pending、地形原码等；对每个影响规则字段做差分反例。不能证明完整时用完整状态hash作重复诊断，不发明平局规则。
- RNG独立分为对手、候选、教师查询、采样/开局、训练验证；保存算法、种子、调用数及可恢复内部状态。配置字段必须被实际消费，禁止DAgger教师查询改变对手轨迹。
- 用真实恶意策略覆盖：改输入状态、改候选、非法动作、NaN logits、空动作、同步死循环、慢决策、step拒绝、终局与截断边界；正例包括首次收入、clone不变性、招募pending、技能状态、投降。

**轮3：依据诊断只选一个主要方向。** 若编码反例主导，增加必要表示信息并更新schema，重跑parity和碰撞检查，旧权重只迁移兼容层；若行为覆盖不足，优先数据/损失改进；若监督已饱和、标签质量和价值口径合格、预算足够，才允许有限RL。RL须分自然终局与截断bootstrap，保留监督锚点及不使用RL的等预算对照。若教师质量不足，可做有限B100蒸馏，模型在线推理仍无搜索。没有证据就不增加架构/搜索复杂度。

领先**完整配方**用第二seed重训复核：源码、数据、初始化来源、超参、预算、选模规则完全相同，唯一允许不同的是随机流。若领先为轮2/3多轮配方，第二seed按同样链条执行，不能只重做最后1200步却称全流程复现。保存机器可读配置diff；第二seed未完成则明确缺项，不称稳定。scratch若显示同等或更好收益，应选scratch，不为复用旧成果强留暖启动。

## 总预算、内部调度与停止条件

建议本大阶段计算墙钟上限仍为12小时，从首次计算作业开始用父调度器单调时钟计时，包含采样、测试、训练、评测；并行不延长截止。CPU/GPU累计时、峰值内存与磁盘增量另记，不能拿子进程耗时和代替墙钟。线程上限按WP0资源确定，默认单训练进程、受控评测并发；不得无授权创建外部付费算力。

| 工作 | 计划墙钟上限 |
|---|---:|
| WP0/1合同、冻结、恢复与parity | 1.2小时 |
| WP2诊断与统一历史DEV | 1.2小时 |
| WP3数据重建/采样/验证 | 1.6小时 |
| WP4轮1等预算对照 | 1.5小时 |
| WP4轮2 DAgger | 1.3小时 |
| WP4轮3证据分支 | 1.3小时 |
| WP4领先配方第二seed | 1.5小时 |
| WP5/6验证、FINAL、清理交付预留 | 2.4小时 |
| 总计 | 12小时 |

前9.6小时内部可根据实测成本重分配，但不得借用最后2.4小时继续正式训练。为第二seed预留其完整配方实测成本，必要时缩小主配方共同预算或跳过轮3；不事后少训第二seed却声称相同。训练时间不是必须耗满的配额：提前满足可信目标、明确瓶颈且继续无信息增益、或不可恢复阻塞，可提前结束并给证据。

硬停止：保护资产意外变化、规则/对手漂移、无法隔离的泄漏、硬超时监管失效、不可恢复磁盘风险、9.6小时训练截止或12小时总截止。硬项失败停止依赖它的训练/计分，继续不受影响的只读诊断和报告。性能差但系统正确不是立即停止整个阶段的理由，应沿内部失败分支推进。预算用尽后不自动安排新一轮训练。
