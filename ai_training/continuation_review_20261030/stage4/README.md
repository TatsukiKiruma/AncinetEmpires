本目录是本次用户授权的无权重训练研究工作。独立大文件根目录：`D:\AncientEmpiresData\continuation_stage4_20261031_v1`。阶段一至三与历史D盘目录只读引用，前端默认模型不变。

工程实现位于公共纯TypeScript运行时`src/ai_runtime/dual_v3/`。`batched_beam_search.ts`执行异步波次搜索；`search_value.ts`负责多人效用与生存否决；`search_teacher.ts`负责带掩码的根策略教师目标。Node与Python桥仅在本目录内。

当前接续入口为`RESUME_V3_PLAN.json`与三个原封不动的`config-v2-*.json`。`PLAN_V2.json`及旧控制器启动记录保留，不应再次运行旧入口。首版整盘开发冒烟完整率不足，已保留原始记录与`revisions/response-health-v1/`源码快照；首个控制组在44步工程停止，没有计作自然负局或消融成绩。修订说明见`ENGINEERING_REVISION_V2.json`。旧效用是受控对照，完整开发54局结束后才写唯一候选锁。`arena.ts`在读取封存面板前校验锁、模型、源码与唯一尝试令牌，且拒绝已存在输出目录。

第二版已保存28条正式开发记录：旧效用18条、Max^n先验1.0为10条（含`p3-12-s0`推理超时失败），先验0.35尚未开局。`PRESERVED_GAMES_V3.json`冻结原始文件摘要，接续期间逐阶段核验；自然局、截断局和失败局都占用原局号，不覆盖、不重跑。预筛仅补余下26局。优胜配置进入完整54局开发面板时，复用它的18条预筛记录，只补36条未评局。旧推理失败不追改分类，不用诊断冒烟的成功结果替换；开发消融存在运行时版本混杂，报告必须披露。

故障机制和修复证据见`GPU_TIMEOUT_DIAGNOSIS.json`、`GPU_TIMEOUT_REPAIR_CHECK.json`，修复前源码保存在`revisions/gpu-timeout-v2-20261031/`。搜索预算耗尽只终止本根扩展，保留已经完成的合法候选；常驻GPU继续排空迟到响应，下次请求必须等待前包收齐，防止串包。真实传输失联使用独立10秒看门狗，保留失败局并只为下一未评局重建服务。时间判负由冻结面板的实际`maxDecisionMs`超限判定。失败前日志没有记录最后一个请求，不能据此断言GPU硬件故障或声称精确复现了慢请求。

正式控制器：

```powershell
node ai_training/run.mjs node --import tsx continuation_review_20261030/stage4/resume_controller.ts
```

控制器不接受重复启动。已通过的第二版独立开发整盘冒烟及其健康记录原样保留。接续顺序为：公共lint/test/build与独立类型、协议及断点接续回归、统计/I-O合同检查 → 修复后的GPU一致性 → 三配置固定18局预筛补齐 → 优胜Max^n配置完整54局开发补齐并核验原健康门槛 → 唯一锁定 → 历史40局 → 唯一封存54局 → 聚类bootstrap、四局痛点合法重放、完整遥测与中文报告 → 关闭所有本次推理和评测子进程。没有配置满足门槛时保留全部证据并停止，封存保持未访问。

运行时只读监控已发布的不可变`RESUME_RUN_STARTED_V3.json`、`SCHEDULE_AUDIT_*.json`、D盘`logs-resume-v3/*.json`和新目录内逐局`result.json`。旧`RUN_STARTED_V2.json`和`logs-v2/`只作历史证据，不能据此判断进程存活。`PROGRESS.json`只是原子替换的用户进度显示，不把打开的进度句柄作为结果依据。`RUN_CLOSED.json`与`REPORT.md`均在真正完成后生成；它们缺失时不能宣称第四阶段验收完成。异常会生成新的`RUN_FAILURE_*.json`并停止后续调度，保留已有尝试，不自动重跑封存。

完整实战需要较长墙钟时间，3000ms是每个根搜索上限而非每局预算；每局仍沿用原200回合、10000动作、30分钟和120秒决策保护合同。正式评测串行执行，避免不同配置互相争用硬件改变搜索完成规模。

教师标签只消费`teacher.available=true`的记录；这时`probabilities`和为1。未完成动作`qValues=null`、`evaluatedMask=false`。完全未闭合根的零向量表示缺失标签，不能当作均匀或低价值策略训练。

复杂响应以小波次优先闭合两个不同根动作，再按剩余预算继续后续波次；延迟候选记为未评估。敌席只在神经预筛的移动行动者及全部即时非移动战术、招募、城堡相关行动者菜单内按自身视角排序。这个计算量取舍会缩小部分移动覆盖，不能宣称全菜单最优敌方响应；完整率和候选覆盖均有独立遥测。

停止可在本目录新建`STOP`文件；它会使在途评测按用户停止单列并阻止新局启动。控制器不会因为历史文档状态自动重启任何旧任务或进入第五阶段。
